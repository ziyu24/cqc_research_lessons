# P29 项目进展

## 最初科学问题

在光学遥感二维 OBB 离线域适应中，仅用两个源模型和无标注目标图像，能否把多源互补转化为单个同容量检测器的收益（MS-01）；额外开放一个源的完整标注数据时，能否获得超过普通源监督相加的收益（MS-02）。

## 核心进展

概率事件错误确实造成了旧融合的大部分损失，修正结果已由 C 独立复算确认。融合 AP50/AP75 从 34.42/21.43 提高到 49.59/35.94，但对应 FAIR 单教师为 50.61/35.63，尚未把互补转成一致的多源收益，更没有同容量学生结果。

目前核心问题是有效候选被替换冲突与排序抵消：IoU 0.5 相对 FAIR 新增/丢失正确匹配各 22，IoU 0.75 为 19/18；净增只有 0/1。不能把概率语义修正当成多源创新，也不能从低分 FP 总数认定 AP 损失的唯一原因。
