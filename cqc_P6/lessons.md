# cqc_P6 避坑点

审计基线：`ziyu24/cqc_P6@dcd648484879418bd094cea71184d81a8e724fd6`

## P6-01 短周期微小正号不能包装成增益

- 类型：范围限制。
- 为何失败：r009 六 epoch、单任务、单 seed 只得到 `+0.001261` mAP fraction，且延迟与数据身份未闭合；这只能记 `NO_EARLY_SIGNAL`。
- 避坑：把早期筛查当淘汰工具，未达到预注册效应量和有效性门时不使用“有提升”措辞。
- 边界：不否定长训练或不同假设，只禁止反复用同一低信息筛查续命。
- 证据：`ziyu24/cqc_P6@dcd648484879418bd094cea71184d81a8e724fd6` 的 `lab/failed_methods.md`、`lab/result.md`。
## P6-02 策略交互为正不能覆盖绝对性能全负

- 类型：科学证伪。
- 为何失败：r012 的策略差分之差为正，但综合和两个任务增益为负，M03 跌破下限，且通用/随机缩减即可解释；冻结候选正式为 `SCREEN_NEGATIVE`。
- 避坑：合取门逐项报告，不能挑一个正交互掩盖绝对收益、任务下限和强对照失败。
- 边界：仅限冻结候选、任务、预算和 seed，不外推全部压缩方法。
- 证据：`ziyu24/cqc_P6@dcd648484879418bd094cea71184d81a8e724fd6` 的 `lab/failed_methods.md`、`lab/result.md`。

## P6-03 机制效应未过门后不得事后重选扰动

- 类型：科学证伪。
- 为何失败：r013 的缩小交互仅 `+0.002661<0.005`，方向交互为负；位置、强度、样本和阈值若在看过 AP 后再改，会把同一失败变成选择性报告。
- 避坑：成分、扰动和阈值在读结果前冻结；两项核心交互失败即停，不追加同类结构搜索。
- 边界：不否定所有几何局部性，只否定该协议下的主张。
- 证据：`ziyu24/cqc_P6@dcd648484879418bd094cea71184d81a8e724fd6` 的 `lab/failed_methods.md`、`lab/result.md`。

## P6-04 前提效应不存在时不能解释分解机制

- 类型：协议/实现无效。
- 为何失败：r014 没有复现预期的 `AP50` 保持而 `AP75` 大降，实际变化远小于 `-0.05` 且 bootstrap 含零；在总效应缺失时，中心/形状或角度 oracle 的恢复比没有目标机制含义。
- 避坑：先验证待解释的总效应，再运行分解；总效应门失败时停止因果归因。
- 边界：逆变换等变误差仍可描述，但不能冒充 AP75 脆弱性的原因。
- 证据：`ziyu24/cqc_P6@dcd648484879418bd094cea71184d81a8e724fd6` 的 `lab/failed_methods.md`、`lab/result.md`。

## P6-05 直接教师响应监督会与标注目标冲突

- 类型：科学证伪。
- 为何失败：r015 的教师和前置门有效，但直接框残差/跨视图响应候选 AP75 近零，相对正常对照约降 `0.696`；FGD 与 Orientation Distillation 未同样崩溃，说明不是整套训练或评估失效。
- 避坑：教师响应进入学生前先隔离其与标注监督的目标冲突，并设公开 target-conflict 强对照；不得靠调权重、扰动或轮数改名挽救。
- 边界：不否定教师定位知识或所有蒸馏，只否定冻结的直接输出头监督。
- 证据：`ziyu24/cqc_P6@dcd648484879418bd094cea71184d81a8e724fd6` 的 `lab/failed_methods.md`、`lab/result.md`。
