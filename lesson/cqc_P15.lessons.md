# cqc_P15：检测错误历史与重复训练收益

## 快速阅读路径

## 项目研究什么

在不增加教师的前提下，检测器的对象错误历史能否在当前难度之外预测“再训练一次”的增量泛化收益，并最终改善计入观测、估计和训练成本的等时间检测精度？研究对象是收益与训练时机，不是单纯重访高loss样本。

## 领域位置与当前结论

历史采样、复习与泛化收益选择已有相关方法，名称或工具组合本身不是创新证据；定位见来源`doc/related_work.md`。普通检测器在当前配置中能够学习：开发集AP50从12轮8.752升至36轮74.897。早期低性能不能代表后续阶段。

固定36轮状态下，已测试的六次IoU统计/趋势加Ridge没有显示额外预测支持，停止扩展该表示。完整错误轨迹、其它估计器和实际等时间调度收益尚未知。有限负结果没有证明一般历史方法或重复训练无效。后续两个训练条件的诊断中，全局收益秩相关接近零，但预设前四分之一交叉选择均有正收益；联合投入参考未通过，局部正线索仍保留。

## 实际采用过的方法

HRSC2016单类检测，固定种子42，训练/开发/描述性留出348/88/181图；R50-FPN Oriented R-CNN，batch8、学习率0.0025。先在早期锚点比较重复与间隔，再恢复未舍入AP并核对普通学习曲线；后续在36轮做32组不重叠八图候选的两臂配对，每臂42更新，共64分支，最后曝光时刻及后续背景更新受控。

预测目标是开发集末端AP50的连续第二次曝光减一次曝光。四折按候选组划分，比较Current与静态、有序、固定打乱旧历史。实际历史为六次连续IoU统计及趋势；另一“整图无预测”通道全零，不是GT漏检轨迹。Current的面积未归一化，单图loss诊断也未实现规定的随机状态恢复，因此不称完整错误历史协议已验证。描述性留出此前已被查看，官方test未使用。

后续复用同一36轮模型/优化器，在原候选中按ID/fold固定16组，每组在两个预定背景/增强条件下做两臂，共64分支、2688更新，仅评估开发集最终端点。同条件所有候选共享背景，背景排除已选候选；同候选两条件固定同设备，基础模型仍为单种子。保存实际事件、终点模型/优化器/RNG及原始预测。此诊断没有拟合新历史表示。

另一条已完成的选择路线是AFSS型图像采样适配：从公开ImageNet初始化训练，共享12轮528次更新后，比较普通随机采样和按训练图像P/R充分度分组、带防遗忘重访的采样。普通基线固定72轮3168次更新；两臂按相同更新数调整学习率，AFSS另保存记录时钟达到基线预算的端点。共42次全训练集评分；实际选图、批次、补齐、增强种子及学习率均按冻结规则重建一致。同更新数下开发集AP50/AP75下降2.3937/6.4059个百分点，当前配置没有显示收益。记录时钟端点同样下降，但部分开销漏计，尚不能声明严格全部成本等时间比较完成。

## 教训一：历史增量必须相对于同一时点、真实可观测的当前状态解释

- 失败命题：把早期简化特征的阴性预测结果，或已经混入历史的Current对照，解释成“对象错误历史没有增量信息”。
- 失败原因：早期检测器质量低，普通延续随后大幅提高，阶段条件并不等价；原分析还曾使用锚点之后观测。后续Current的IoU又误取整个六次窗口均值，实际对照已经含历史。另一个被称为漏检历史的通道实际上只标记整图无预测，且全零。上述条件均不能支撑对完整对象错误轨迹的广义否定。纠正时点后，Current与静态/有序历史的MSE为3.2185与3.9962/4.2793，仍仅支持实际IoU表示的有限负结果。
- 后续做法：明确当前、历史窗口和预测未来的时间关系，用锚点当前观测构造Current；按保存数据的真实语义命名表示，并在无效通道或未实现协议存在时收窄结论。普通模型的学习正证据与某个收益表示的负结果分别保留。
- 边界：这是比较信息条件与结果归因的修正，不是完整错误轨迹有效的证据。单种子、单类、固定阶段和低维回归结果均不能外推为普遍零效应；也不自动要求重跑或添加复杂估计器。
- 证据：`ziyu24/cqc_P15@e2b0f9442de5a9c33b71ccf9a8e109935fe4de2d`；`lab/result.md`记录分阶段AP、实际字段与无重训修正；`src/analyze_mature_probe.py`和`src/test_analyze_mature_probe.py`对应当前时点与历史隔离；`src/run_mature_probe.py`记录实际历史采集；`doc/mature_repeat_probe.md`给出原协议边界。

## 教训二：候选收益分散和事后正子集不足以支持继续训练调度方法

- 失败命题：只要配对收益有正有负，或预测排序的前四分之一实际均值为正，就足以支持增加历史估计器、扩大重复实验或进入等时间调度。
- 失败原因：32组末端开发集净差均值-0.1764 AP百分点，14组为正，范围[-3.7742,+3.7544]；分散既可能包含真实差异，也可能包含当前有限实验的变动，未被分离。Current的MSE=3.2185，静态/有序历史更高；补充训练折均值参考为2.9421。Current选取子集虽有+0.2552，但没有证明历史增量或上线净收益。原“难例”正收益来自排序方向反转，真正难例子集均值为-0.4299。描述性留出也不足以充当新盲测。后续16组两条件诊断的AP50平均净收益为+0.2920/+0.8662，Spearman=0.0206，描述区间[-0.6342,+0.5692]；但双向交叉选择净收益+1.1277/+1.2934、相对目标条件全组均值的增益+0.2615/+1.0014，均为正。因此整体排序缺少支持与局部选择正线索可以同时成立，不能互相替代。
- 后续做法：同时报告完整配对均值、分布、冻结折预测与无特征参考，把子集描述和独立部署验证分开；在已定预算内完成核心性能信号后，依据缺少增量支持停止扩展已测表示。新方案须提出独立机制依据和可负担的区分性验证，不能靠不断加种子、组数或方法复杂度追求阳性。提前区分全局排序与局部选择目标；未通过联合投入参考时保留每项指标的真实结果，不能事后改阈值，也不能用一个低相关值抹掉预设选择的正线索。
- 边界：停止的是六次IoU统计/趋势加Ridge这一具体投入，属于经验止损，不是证明真实效应为零。无特征参考是事后审计补充；尚未完成在线调度或全部成本下的等时间比较。前次主端点预测保留，辅助端点原预测被覆盖与随机恢复记录不足也限制精确重建声明。后续条件间诊断虽保存了完整事件和终点状态，但相同干预前输入/种子在第二至八步已出现loss差异，最大0.0077613；根因及AP贡献未知，不能把低相关仅归因于背景/增强。两条件、固定开发集和单锚点不足以分离所有变异，反事实选择也不是理论上界或可部署方法。
- 证据：`ziyu24/cqc_P15@e2b0f9442de5a9c33b71ccf9a8e109935fe4de2d`；`lab/result.md`给出完整配对统计、交叉拟合、补充参考及成本/恢复限制；`src/analyze_mature_probe.py`定义收益、折划分、难例方向和参考；`configs/hrsc_mature_probe_manifest.json`保存固定候选；`lab/failed_methods.md`及`lab/discussion.md`限定止损范围；`src/analyze_gain_reproducibility.py`、`src/run_gain_reproducibility.py`和`doc/gain_reproducibility.md`对应新增两条件诊断、实际执行及预先定义的分析。

## 教训三：图像充分度采样迁移必须用固定末端性能和实际观测成本裁决

- 失败命题：把学习充分度分组与防遗忘重访迁移到旋转检测器，就能在固定更新数或实际时间预算内提高精度；或者早期曲线领先足以证明最终收益。
- 失败原因：这次HRSC适配中采样确实执行，42次评分后的选择可由保存统计重建；但固定3168次更新的开发集AP50/AP75从普通随机采样的80.5278/36.5165降至78.1341/30.1106，描述性留出从90.1542/49.2878降至87.7886/36.2450。早期约1个百分点的AP50领先未保持到预定末端。全训练集评分累计约926秒增加观测成本；按已记录时钟到达预算的端点也更差。具体是阈值、训练分布、检测器适配还是其他机制导致，现有对照没有分离，不能编造单一根因。
- 后续做法：先验证实际选择与固定训练日程，再同时保存同更新数和明确成本口径的时间端点；观察者评分、选图、状态恢复和必要写盘均须在宣称全部成本比较前纳入。固定末端负结果支持停止当前配置的扩展，不能通过事后选择早期最高点或连续调整阈值来改写已完成比较。
- 边界：这是HRSC单类、单种子、R50-FPN Oriented R-CNN上的AFSS型适配，不是原方法跨架构复现或所有选择策略的否定。官方test未使用，描述性留出不是新盲测。旧报告误用训练最终总时间描述预算端点，实际记录时钟超出约0.64秒；纠正报告不改变同更新数AP下降。由于选图、恢复及部分写盘未完整计入，不外推严格全成本等时间结论。保存的训练评分仅含P/R统计，不能独立复算原始匹配几何；恢复游标也未完整保存，不能称逐位复现已通过。
- 证据：`ziyu24/cqc_P15@5a253f0b75b08fce22631abafeed89bd832300b9`；`lab/result.md`、`lab/failed_methods.md`保存端点性能和无重训审计边界；`src/afss_sampling.py`、`src/run_afss_training.py`记录实际采样和计时实现；`src/audit_afss_training.py`重建事件与端点时钟；`configs/afss_hrsc.json`和`doc/afss_hrsc_training.md`给出冻结配置与协议。

## 方法族停止索引

| 方法或主张 | 当前裁决 | 不应外推到 |
|---|---|---|
| 早期缩减历史加轻量回归 | 未显示增量；撤回一般历史无效解释 | 成熟阶段或完整错误轨迹 |
| 36轮六次IoU统计/趋势加Ridge | 本次固定预算后停止扩展 | 所有历史、其它估计器或数据集 |
| 两固定训练条件的候选收益迁移 | 联合投入参考未通过；保留局部选择正线索 | 不等于收益不存在，也未识别变异根因 |
| HRSC上的AFSS型图像充分度与防遗忘采样 | 固定末端精度下降，停止当前配置扩展 | 原AFSS、其他适配和所有选择策略；严格全成本结论仍受计时限制 |
| 卡尔曼与在线等时间重复调度 | 尚未验证有效，暂无新增训练任务 | 不登记为已验证科学失败 |
| 普通检测器学习能力 | 保留实测正结果 | 不声称完全收敛或跨种子稳定 |
