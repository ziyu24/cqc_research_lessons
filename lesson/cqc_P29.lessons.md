# P29：多源旋转检测的候选融合边界

## 快速阅读路径

先读来源 `README.md` 与 `lab/discussion.md` 的 MS-01/MS-02 信息条件，再读 `lab/result.md` 和 `lab/failed_methods.md` 的三轮冻结双教师诊断；结合三个完成审计、`src/run_diagnostic.py`、`src/run_projection.py`、`src/run_fusion.py` 与对应协议模块核对教师投影、共同候选、旋转 NMS、ProbEn 适配和覆盖统计。当前审计来源为 `ziyu24/cqc_P29@5b2727e7993cb7dbc0ac073f3590116fd7dea0b9`；已检查全部远端分支，仅 main，没有更新更晚的次线。

## 项目研究什么

在光学遥感二维 OBB 离线域适应中，仅有两个不同源域训练的模型和无标签目标图像时，能否把多源互补转化为单个同容量检测器的收益；额外开放一个源的完整图像与 OBB 标签时，能否获得超过普通源监督相加的收益。当前先定位教师候选、跨模型融合和学生学习中的损失环节，不把不同训练方法的同源模型、在线适应或模型压缩混入问题。

## 领域位置与当前结论

首次诊断固定 DOTA 四类教师与 FAIR 37 类教师，在 HRSC val 的船类投影上做零训练前向。两教师存在候选互补，但把 DOTA 粗类概率与 FAIR 最大细类概率直接混排会删除大量并集已覆盖目标。第二轮改用九船类概率之和，明显减少损失并提高融合 AP，但没有在 AP50/AP75 都超过对应 FAIR 单教师。第三轮的分组控制几乎复现该融合；固定输出集合复算证实，均匀二元 ProbEn 后验主要损害排序，无定位方差的置信度加权旋转框主要损害严格 IoU；NMS集合改变不足以解释这些下降。输出预算始终不是主要损失。当前仍未证明可靠的无标签定位质量判断、学生收益或整个多源适应命题。

## 实际采用过的方法

- 固定两个可追溯源模型，权重全程冻结；DOTA 只取 ship，FAIR 将九个船舶细类先按原细类分数做跨细类旋转 NMS 后投影为 ship。
- HRSC val 181 张开发图像各做一次单视图前向，等比例缩放到 1024 范围；最低分数 0.001，每教师每图最多 2000 个投影后候选。
- 比较 DOTA、FAIR、候选并集经旋转 IoU 0.1 NMS、以及再按每图两教师较大输出数限制预算的四个视图；使用原生旋转 VOC07 11 点 AP50/AP75 和完整 PR。
- 以 GT 只做开发诊断：统计 DOTA 独有、FAIR 独有、共同、均未覆盖，以及 NMS 和预算分别删除的已覆盖目标；这些量是候选潜力，不是一对一召回或可部署 oracle。
- 第二轮只新增一次 FAIR 冻结前向，保存每个 class-agnostic ROI 的完整 37 类加背景 softmax；max/sum 两臂严格共享以最大船类概率过 0.001 筛出的 ROI，只改变船类分数事件，同时重建旧 native 细类 NMS 输出并逐图核对。
- 第三轮不做教师前向；按最高分种子和旋转 IoU 0.5 分组，每教师最多一票，比较组内 max、二元后验乘积保留原框、以及同后验加原置信度加权的周期旋转框，三臂再统一做 NMS 0.1 与固定预算。

## 教训一：候选互补不保证固定跨源 NMS 保留覆盖

- 失败命题：若两个源教师有互补候选，则把它们按各自原始分类分数合并并做普通跨源旋转 NMS，就能保留互补并至少不劣于较强单教师。
- 失败原因：IoU 0.5/0.75 下，并集潜力分别覆盖 437/301 个 GT，其中 NMS 删除 63/80 个，占并集潜力 14.42%/26.58%；直接抑制边中 FAIR 有效候选被 DOTA 候选压制为 59/75 条，反向仅 4/5 条，证明这项混排规则删除了有效覆盖，但不能由抑制方向唯一识别校准根因。融合 AP50/AP75 为 0.344194/0.214302，低于 FAIR 单教师的 0.388709/0.225042；后续预算限制额外删除均为 0，因此不能把损失归给输出上限。独立多边形复算所有图的 NMS/覆盖与原结果一致，全部八份 PR 的 AP 复算一致。被删目标中，61/63 与 80/80 也是抑制框最近 GT，没有抑制框在对应阈值下正确覆盖另一 GT；此为描述性关联，不等于真实实例归属。旧文把抑制方向解释成分数不可比的确定根因，现收窄：粗类船概率与最大船舶细类概率不同，且定位质量未被控制，尚不足以识别唯一原因。
- 后续做法：先核对分数是否描述同一类别事件，再检查与定位质量的关系和直接抑制来源，并保留单教师、未抑制并集潜力和同预算视图。只有不依赖目标标签的分数对齐或冲突规则实际保住候选、相对对应单教师有可比收益且后续学生指标改善，才能称互补被转化为可实现收益；不要用 GT 潜力替代方法结果。
- 边界：只约束当前 DOTA/FAIR 教师、HRSC 开发集、异类别头船类投影、分数下限 0.001 和 NMS IoU 0.1。FAIR 教师并非严格同四类模型，跨源—HRSC 内容重复尚未闭合，单开发集没有跨种子或 SODA 主实验结论；不否定经校准融合、学习式匹配、其它 NMS 阈值的预注册比较或整个 MS-01/MS-02。
- 证据：`ziyu24/cqc_P29@c64c9687320d98a9f575e29064ad480ed32eab02` 的 `lab/result.md`、`lab/failed_methods.md`、`lab/discussion.md`、`configs/r001.json`、`configs/r001.audit.json`、`src/run_diagnostic.py`、`src/diagnostic_protocol.py`、`configs/r001.review.json` 与 `src/review_frozen.py`。

## 教训二：对齐类别概率事件能修复旧排序，但不足以保证多源胜过强教师

- 失败命题：只要把细粒度教师的多个互斥子类概率相加为与粗类教师一致的事件，简单跨源 NMS 就会稳定超过对应强单教师，从而已经把教师互补转化为多源收益。
- 失败原因：共同资格池固定为 55,250 个 ROI，并明确排除 8,206 个仅概率和过线的候选后，sum 相对 max 的 union AP50/AP75 从 0.344194/0.214302 升到 0.495909/0.359431，NMS 覆盖损失从 63/80 降至 27/26，NMS 后覆盖从 374/221 升至 412/288，预注册联合条件通过。这证明概率事件不一致对旧失败有贡献。但对应 FAIR sum 单教师已经达到 0.506138/0.356322；sum 融合相对它为 AP50 -0.010229、AP75 +0.003108，方向混合。C 独立核对全部 ROI 资格/分数、跨源 NMS 与十二条完整 PR 后结果一致。相对 FAIR sum，一对一正确匹配在 IoU 0.5 新增/丢失各 22，在 0.75 为 19/18；净正确目标增量仅 0/1。修正分数语义后，已有互补仍被替换冲突及排序抵消；总低分 FP 数量不能单独说明 AP 原因，尚未证明定位质量是唯一剩余瓶颈。
- 后续做法：任何下一融合或学生机制都应把 `fair_sum` 与 `union_sum` 作为更强对照，直接检验不依赖目标标签的定位质量估计、冲突监督和学生迁移。必须同时报告相对对应单教师的增减，不能只报相对错误 max 基线的大幅提升；也不要继续用开发 GT 扫阈值或拟合校准器。完整 softmax 及逐图直接抑制关系可复用，避免重跑教师猜原因。
- 边界：当前正证据只说明 DOTA ship 粗类与 FAIR 九船类投影在 HRSC val、共同候选和 NMS IoU 0.1 下的概率事件控制有效；不证明其它类别、其它域、严格四类教师或无标签校准普遍有效。单开发集、单种子冻结诊断没有学生训练、SODA 主实验或跨种子稳定性。
- 证据：`ziyu24/cqc_P29@673f9ce8561829a49dd25c4d6178ae3621f8d614` 的 `lab/result.md`、`lab/discussion.md`、`lab/failed_methods.md`、`configs/r002.json`、`configs/r002.audit.json`、`configs/r002.recovery.json`、`src/run_projection.py`、`src/projection_protocol.py`、`configs/r002.review.json` 与 `src/review_projection.py`。

## 教训三：同图教师的概率乘积和分类置信度框平均不能代替定位质量

- 失败命题：修正类别事件后，把同组双教师的二元 ship 后验相乘，并以分类置信度加权旋转框，就能利用共同证据并超过 FAIR sum 与 union sum。
- 失败原因：8365 个冻结候选形成 7012 组，其中双教师组 1353；`group_max` 相对 `union_sum` 的 AP50/AP75 仅 +0.000028/0，排除了分组次序作为主要影响。二元后验排序相对分组控制降低 0.043218/0.041059 AP，旋转框加权再降低 0.000638/0.022049；预定主臂最终为 0.452082/0.296323，低于 FAIR sum 0.506138/0.356322 和 union sum 0.495909/0.359431。相对 FAIR，主臂在 IoU 0.5 新增/丢失正确匹配 22/25，在 0.75 为 22/36。原“只改分数”对照同时新增17/移除18个NMS组，原“只改框”对照又新增28/移除54组，因此当时不能仅据两臂差异声称纯排序/纯坐标原因。补充固定集合后，只换分数仍令AP50/AP75下降0.042987/0.040908，随后NMS选择变化仅再降0.000231/0.000151；固定后验输出集合与分数，只换平均坐标令AP75下降0.022155、TP287→273，随后NMS变化回升0.000106。原十二条及新八条完整PR均经独立多边形几何核验。当前主要环节归因由此补足，但AP分解依干预顺序，不能当普适唯一贡献比例。同图输入不能证明条件依赖；先验、校准和相关性均未被分别识别，共同误检增信只是反例。分类置信度不是定位方差。
- 后续做法：保留 `fair_sum`、`union_sum`、`group_max` 和当前负基线。下一步用原生候选分配/必要梯度检查核实学生实际收到的冲突监督，并与单教师参照区分错误框和缺失证据；没有证据就放弃对应动机。若进入学习式质量/冲突监督或学生迁移，先说明不使用目标标签的质量信号来源，并直接测一对一正确匹配和 AP；不要扫描先验、分组阈值、NMS 阈值，或把控制臂改称主臂。没有方差头时，不把分类分数包装成 ProbEn 的方差加权定位。
- 边界：只否定当前 HRSC val、同图 DOTA/FAIR 教师、均匀二元先验、分组 IoU 0.5、最终 NMS 0.1、每教师一票及置信度加权周期旋转框的适配。它不是 ProbEn 原 RGB/thermal 基准或学习方差版本的完整复现，也不否定其它有依据的无标签质量估计和学生适应。
- 证据：`ziyu24/cqc_P29@5b2727e7993cb7dbc0ac073f3590116fd7dea0b9` 的 `lab/result.md`、`lab/discussion.md`、`lab/failed_methods.md`、`configs/r003.json`、`configs/r003.audit.json`、`configs/r003.recovery.json`、`src/run_fusion.py`、`src/fusion_protocol.py`、`src/check_fusion.py`、`src/run_fusion_review.py`、`src/review_fusion.py`、`configs/r003.review.json` 与 `configs/r003.fixed_review.json`。

## 方法族停止索引

- 未校准原始分数的固定跨源旋转 NMS：在当前协议下已失败，停止把它当作保留互补的默认基线或继续做目标标签驱动微调。
- 输出预算限制：本轮额外覆盖损失为零，不作为当前主要瓶颈；不同预算或部署约束尚未被普遍否定。
- 相同候选的粗类概率控制：已确认能修复旧 max 排序的大部分损失，但没有跨 AP50/AP75 一致超过对应强单教师；停止把它单独包装为已解决的多源机制。
- 均匀二元 ProbEn＋无方差置信度加权旋转框：当前适配两项 AP 均明显下降，停止扫描先验/阈值或继续普通框平均；原方法其它信息条件和学习方差版本不在停止范围。
- 无标签定位质量/冲突处理和学生学习：尚无可裁决性能，不根据候选潜力或概率控制结果登记成功或失败。
