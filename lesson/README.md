# lesson 目录

> 使用边界：教训须结合适用条件与原始证据使用，同条件下的有效反证不能忽略，也不能跨条件自动否决新研究；来源不可访问时须注明“未独立核实”，不得将摘要当作已核实的原始证据。

本目录集中保存按 GitHub 精确仓库名命名的科学失败教训：`<仓库名>.lessons.md`。目录保持单层；没有同名文件只表示尚无已登记教训。

任务开始时先确认当前项目的精确仓库名，然后完整读取对应文件：

- 网页：`https://github.com/ziyu24/cqc_research_lessons/blob/main/lesson/<仓库名>.lessons.md`
- Raw：`https://raw.githubusercontent.com/ziyu24/cqc_research_lessons/main/lesson/<仓库名>.lessons.md`

新增或修订总结的完整步骤见根目录 `README.md` 的“项目如何新增或修订总结”；全部仓库与当前证据边界见根目录 `INDEX.md`。
