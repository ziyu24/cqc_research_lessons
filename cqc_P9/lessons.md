# cqc_P9 避坑点

审计基线：`ziyu24/cqc_P9@ab53c8bebe9849796d7e34e7b6afb21a4513dc1a`

## P9-01 训练前的数据接线错误不是方法失败

- 类型：工程失败。
- 为何失败：r005--r008 先后因丢弃空切片、缺少自定义数据集导入、把图像目录接到 `ann_file`、以及 train loop 合并残留 `max_epochs` 而在优化前退出；没有 checkpoint 或指标。
- 避坑：先用真实 DataLoader 同时读取有标注/空切片并构造 train/val loop；普通配置和导入问题在同一任务内修复，不升级为科学结论。
- 边界：这些记录既不支持也不反对 TRB。
- 证据：`ziyu24/cqc_P9@ab53c8bebe9849796d7e34e7b6afb21a4513dc1a` 的 `lab/failed_methods.md`、`lab/result.md`。

## P9-02 数据资格硬门必须先做零成本可满足性审计

- 类型：协议/实现无效。
- 为何失败：r002 要求四个语义混淆组和目标外九个高支持叶类，但 HRSC2016 只有三个父类、九个达支持叶类，结构上不可能满足。
- 避坑：写实验协议前先统计官方层级、支持数和目标移除后的可行集合；不可满足即改科学问题或数据，不消耗训练。
- 边界：该结果不是 TRB 机制负面，不得降低组数/支持阈值后沿用同一任务身份。
- 证据：`ziyu24/cqc_P9@ab53c8bebe9849796d7e34e7b6afb21a4513dc1a` 的 `lab/failed_methods.md`、`lab/result.md`。

## P9-03 前置召回门失败后下游身份结论不可解释

- 类型：科学证伪。
- 为何失败：r001 的 ship/vehicle 所有组合都无法形成 recall `0.90` 操作点，因此身份抑制、非劣和结构读出等后续判据不再可评；有限攻击器仍高读出也不支持“身份消失”。
- 避坑：按裁决顺序执行；基础任务门失败时只停止该路线，不挑下游诊断包装成成功。
- 边界：不证明所有任务相关拒绝表示都无效。
- 证据：`ziyu24/cqc_P9@ab53c8bebe9849796d7e34e7b6afb21a4513dc1a` 的 `lab/failed_methods.md`、`lab/result.md`。

## P9-04 冻结特征读出不能代表完整检测器可压缩性

- 类型：范围限制。
- 为何失败：在固定母模型特征上训练轻量 probe，既不改变真实检测训练，也不提供静态输出结构和部署代价；高/低可读性不能直接推出检测器能否裁剪。
- 避坑：结构压缩主张必须在真实检测训练、推理图、参数/FLOPs/延迟和任务指标上验证。
- 边界：冻结 probe 可作诊断，不可作压缩结论。
- 证据：`ziyu24/cqc_P9@ab53c8bebe9849796d7e34e7b6afb21a4513dc1a` 的 `lab/failed_methods.md`。

## P9-05 主动停止的重复训练没有科学输出

- 类型：范围限制。
- 为何失败：r009 在只生成 split 后因与 r008 单卡 FULL 重复而停止，未优化、无 checkpoint、无指标；资源避免重复是正确动作，但不能形成方法结论。
- 避坑：明确写 `STOPPED_NO_SCIENTIFIC_RESULT`，不要把“避免重复”解释为验证完成。
- 边界：split 资产仍可复用，科学任务需新有效运行。
- 证据：`ziyu24/cqc_P9@ab53c8bebe9849796d7e34e7b6afb21a4513dc1a` 的 `lab/result.md`。
